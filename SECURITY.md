# Reporting a security problem

Please don't open a public issue for a security hole. Use GitHub's private report instead: the repository's **Security**
tab, then **Report a vulnerability**. Say what you found, how to reproduce it, and what it lets someone do. We'll answer
there.

What counts: anything that lets a model, a web page, a file or another program get past a tool level (README, "Why it
is built this way"), read a Private chat or the app's store, reach the app from another machine without a passcode, or
run commands where the app says it doesn't.
